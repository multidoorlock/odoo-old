# ChatGPT GitHub Connection POC

This file was created through the connected GitHub integration as a proof of concept.

## Scope

- Repository: `multidoorlock/odoo`
- Branch: `poc/chatgpt-connection`
- Base branch: `develop`
- Production code and Odoo behavior are unchanged.

## Purpose

Verify that ChatGPT can safely create an isolated branch, commit a controlled change, and open a draft pull request without touching `main` or `staging`.
